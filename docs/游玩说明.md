## 一、踏入仙途（新手 5 分钟）

```
#开仙途          → 创建角色，出生即判命格（75 种词条，可能天命也可能厄命）
#修仙签到        → 每日修为/血气/灵石；同时结算寿元流逝
#闭关修炼 60     → 挂机修为（60 分钟，上限 7200）
#突破            → 修为够就冲下一境（可失败，扣部分修为）
#状态            → 你的修仙卡片（战力/双境界/资源/装备）
```

- **命格**（`#我的命格`）陪伴你整个仙途：战斗加成、突破成功率、采药采矿产出……
  不满意？`#改命` 花 10 万灵石重演天机。
- **炼体**是第二条境界轨：`#炼体突破` 用血气冲关，与练气取高者决定你的真实位阶。

| 采集 | `#采药 480` / `#采矿 480` | 职业挂机，`#结束采药` 结算 |
| 世界 Boss | `#世界Boss` | 全服共享血条，按伤害分奖 |
| 黑暗动乱 | `#黑暗动乱` | 帝战级共享 Boss |

## 三、赚钱与花销

- **灵石**：签到/秘境/任务/世界 Boss 是主要来源；`#商店` 有消耗品，`#天机阁` 换稀有货
- **赌石**：`#源石坊` 切石头，一夜暴富或血本无归
- **拍卖**：关注宗门与星阁动态
- **疗伤**：`#疗伤` 花灵石回血，重伤先疗再战

## 四、职业线（满 15 境可转职）

```
#职业列表 → #转职 炼丹师（或 采药师/矿工/炼器师/制符师…）
```
- 职业等级靠采集与制作涨经验：采药/采矿直接涨；`#炼丹 配方*数量` 消耗草药出丹
- 丹药分凡品/极品/仙品——命格「炼丹品质」能让你出的好丹更多
- 炼器师可 `#锻造 装备名`，成败看图纸成功率与你的等级

## 五、装备与帝兵

- `#纳戒` 看背包（稀有度配色网格）；`#装备 武器名` 穿戴
- `#强化 武器名` 消耗灵石与强化石提数值
- **本命帝兵**（高阶）：`#炼制帝兵` → 集齐九种仙金 → `#帝兵雷劫` 跃迁品阶
  帝兵认主后战力翻倍，是后期核心战力

## 六、战斗系统（本作最深度内容）

### PvP 三入口
```
#切磋 @道友      → 友切无伤，60 秒 CD
#打劫 @道友      → 胜抢对方 1/5 灵石（+魔道值），败反赔 1/4；对方在闭关？用【隐身水】强行开战；对方有【替身人偶】会免疫
#比武 @道友      → 双方血量须 80%+，6 小时双向 CD，胜负双方都有奖励
```

### 战斗里会发生什么
- **灵根法球**：你的灵根自带每击附加伤害（战报尾缀「，法球 X」）
- **技能池**：灵根自带技能 + 已学功法的战斗技能——出手时掷概率触发
  「【太阳之体】大日灼空！（伤害 ×2）」、防御减伤、控制定身、治疗回血
- **复活技**：学了复活类功法（如凰劫再生术），致死一击时原地复活，一场一次
- **功法熟练度**：`#功法熟练度` 查看；战斗每场 +2 感悟，`#分配功法感悟 功法名*数量`
  转成熟练度——六档从「初窥门径」到「出神入化」，直接加三维与技能触发率

### 开场大招（满足条件自动触发）
| 机制 | 触发条件 |
|---|---|
| **岁云·同境裁决** | 持岁云灵根：把境界比你高的对手压到同级 |
| **高境镇杀** | 双方道果 ≥20 档且有差距：低境者开场直接败北 |
| **帝骑助战** | 诸天镜骑士卡组三卡齐编：开场两道分身合击 |

### 团本
`#创建讨伐队伍 若陀龙王` → 队友 `#加入讨伐队伍 队伍码` → `#发起讨伐` → 每人 `#讨伐出手`
→ 血条清零按伤害占比自动分奖（击杀者 +10%）

## 七、成长线（境界 40+ 的三道门）

1. **渡劫**（第 40 境「无妄真劫境」）：`#渡劫` 双重真劫一次判定——劫数由灵根决定
   （伪灵根 3 道，圣体道胎 128 道），失败血量归 1 且元神 30 分钟 CD
2. **登仙**：渡劫成功后 `#登仙`，飞升地仙，寿元大增
3. **位面旅行**：`#位面` 看诸天星路 → `#穿梭 仙界` → `#抵达` 落位
   11 张位面方图自由探索，`#位面地图` 出图，`#前往 x,y` 逐步发现地点

**寿元**（`#寿元`）：每日签到流逝，体质可减免；寿元耗尽将**轮回转世**（境界清零重头再来，
第几世会记着）。渡劫/登仙会大幅增寿。

## 八、高阶玩法（各成体系）

### 无尽劫境（Roguelike，第 15 境起）
```
#开启无尽劫境 乱古界海 → #星图定途 → #无尽下一关 → #无尽选择 1-3 → … → #无尽撤离
```
10 层劫环：星图三途、道法三选一、劫后问道；带出道痕可在
`#无尽商店` 消费、`#万劫道碑` 永久强化、`#无尽至宝` 装备觉醒、`#称号` 佩戴
（通关解锁「无尽劫境天尊」）。每周首次入场免费。

### 诸天镜主线（P6）
镜阶收集/淬炼/探索/投影/化身；骑士卡片编组 → `#最终攻击驾驭`。

### 大宇宙（P7）
`#大宇宙` 升格 → 法则/灵韵/秘境，仙界后的数值天花板。

### 剧情人物
`#剧情人物` 图鉴（11 位，立绘出图）；秘境寻宝会邂逅柳神/黑皇/张五爷/段德……
好感够了可以 `#请柳神护道`（战败时救命）、`#黑皇请教阵道`（六种阵法，`#启用阵法` 战斗生效）。

### 世界事件
- **千年灾劫**：`#域外灾厄` 看存世灾厄，管理员召唤后全服讨伐
- **灵界裂缝**：`#灵界裂缝` 现世时 `#前往裂缝 x,y` 进入，三路线探索
- **彼岸古文明**：`#彼岸古文明` 推进四章剧情
- **裂界副本**：全服 6 小时窗口，仙界/太初星墟轮换，界源兑换稀有道具
- **小世界工坊**：`#小世界工坊` 种田/守卫/偷菜

### 时间长河（45 重+）
`#遨游时间长河`：30 分钟一段河程——三帝法身连战、观岁月悟道、拾遗、
荒天帝传道（功法熟练度 +2）。岁月结晶累积，见证诸天纪元。

## 九、万界灵市（全服共享行情）

```
#灵市                → 8 张灵票行情（丹鼎阁/天工坊/灵矿商会/万兽山…，10 分钟一 tick）
#买入 丹鼎阁*100     → 低买高卖赚差价（30bps 手续费，30 秒 CD）
#卖出 丹鼎阁*100     → *-1 或省略数量即清仓
#我的灵票            → 持仓/浮盈/已实现盈亏
#灵票走势 丹鼎阁     → 近期走势 + 商会周期（boom/slump/crisis，危机可破产摘牌！）
#打听                → 花 1000 灵石向消息贩买倾向（真假自辨）
#交谈 墨九           → 与 8 位灵市人物闲聊（黑金操盘客正在「护盘」谁？）
#借款 100000         → 向钱万三借钱（日息 10bps，7 天期，逾期 1.5 倍罚息）
#还款                → 连本带息结清
#灵市收益榜          → 全服灵市大亨排行
```

行情由确定性随机引擎驱动：事件冲击、八位 NPC（价值/动量/逆势/操盘风格各异）
拿灵石进出，全服共享同一张走势图。灵市有风险，梭哈需谨慎——问天秘境（高风险）
单日可 ±15%，也可能商会破产直接摘牌。

## 十五、W7-0 机制补齐（4 处断链 + 展示层转正）

- **寿命丹生效**：丹药表的 `shouyuan` 字段此前无人读取，服下不增寿。现在 `#使用 寿命丹` 增寿 10 年；
  同一自然日第 2/3/4 枚药力递减（×0.5 / ×0.25 / ×0.125），每日上限 4 枚，饱和时**不消耗物品**。
- **功法三乘区接通**：`numeric` 乘区此前定义了却零消费，秘境 PvE 也没接熟练度。现在 PvP/PvE 统一在
  `build_fighter → apply_proficiency` 装配：combat 乘开场三维、trigger 乘技能触发率、numeric 乘出手伤害（钳 ≤1.10）。
- **技能链路打通**：注册表此前为空、Fighter 从未挂 skills。现在注册 2 个**纯观测型**共鸣
  （只写战报、不改数值）：熟练度 ≥融会贯通挂「功法共鸣」，练气/炼体均 ≥10 挂「双轨共鸣」。
  有数值的档位专属特效留 W7-4 扩充。
- **展示层读真实档**：补 `位面天骄.json`（5 位）与 `兑换码.json`（空表；明确说明本移植未开放兑换码），
  图鉴支持 `#图鉴 页码` 翻页与真实「已获得」标记；`#练气境界 / #炼体境界` 带下境门槛、消耗与成功率；
  `#我的练气` 带实际三维；`#修仙助手` 读寿元、每日任务进度与渡劫 CD 动态给建议；`#天骄状态` 带掉落预览。

裁剪（已写进 `shortcut:`）：兑换码兑换（原版绑定全局推送群）、有数值的功法特效、天骄定位/仇恨/90 分 CD（W7-3）、
时代轮转（W7-2）。
