# 玩家指南

在已启用插件的群聊中发送以 `#` 开头的指令。指令参数、开放条件和可用系统以机器人返回的帮助信息为准。

## 创建角色

1. 发送 `#踏入仙途` 阅读序章并选择降临方向。
2. 按提示发送 `#降临 修仙界` 创建修仙界角色。
3. 发送 `#修仙状态` 查看角色进度。

如果已经有角色，可从状态、签到或帮助指令继续。

## 日常修行

| 目标 | 指令 |
| --- | --- |
| 领取每日奖励 | `#修仙签到` |
| 闭关修炼 | `#闭关 120分钟`，完成后发送 `#出关` |
| 提升练气境界 | `#突破` |
| 提升炼体境界 | `#炼体突破` |
| 接取每日任务 | `#获取每日任务` |
| 查看任务进度 | `#我的任务` |
| 提交已完成任务 | `#提交每日任务` |
| 查看背包 | `#我的纳戒` |

境界、修为、血气、物品和任务条件会影响指令是否可用；按回复提示准备所需资源即可。

## 探索与战斗

发送 `#进入仙古秘境` 踏入秘境，再用 `#秘境探索` 感知路径并按返回的提示继续。世界 Boss、切磋、比武、队伍挑战等玩法各有独立入口；使用 `#修仙帮助` 或对应系统帮助查看完整流程。

角色成长后还可体验职业与制作、宗门和社交玩法、位面探索，以及无尽劫境和无尽轮回等长线内容。部分玩法有境界、职业、道具或管理员设置要求。

## 查找指令

- `#修仙帮助`：查看帮助目录。
- `#基础帮助`：查看基础指令。
- `#修仙助手`：按当前角色进度获取玩法建议。
- 在帮助目录中选择职业、宗门、诸天、活动或具体玩法的帮助页，查看该系统的指令和条件。

指令会随版本调整；游戏内帮助和实际指令回复优先于第三方攻略或旧截图。
