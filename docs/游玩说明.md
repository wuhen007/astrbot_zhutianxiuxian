# 玩家指南

在启用插件的群聊中使用以 `#` 开头的指令。参数、开放条件和可用系统以机器人返回的帮助信息为准。

## 创建角色

1. 发送 `#踏入仙途` 创建角色。
2. 发送 `#修仙状态` 查看境界、气血、灵石和当前行动。
3. 发送 `#修仙帮助` 或 `#基础帮助` 查找下一步指令。

## 日常修行

| 目标 | 指令 |
| --- | --- |
| 领取每日奖励 | `#修仙签到` |
| 开始并结算闭关 | `#闭关 120分钟`，完成后 `#出关` |
| 提升练气境界 | `#突破` |
| 提升炼体境界 | `#炼体突破` |
| 接取、查看和提交每日任务 | `#获取每日任务`、`#我的任务`、`#提交每日任务` |
| 查看纳戒 | `#我的纳戒` |
| 购买或使用物品 | `#购买 物品名 数量`、`#使用 物品名 数量` |

境界、修为、血气和物品会影响玩法门槛。指令不接受的数量或参数会由机器人提示。

## 秘境探索

本插件有不同的秘境玩法，入口和指令不能混用。

程序化秘境：发送 `#秘境` 查看地点，使用 `#降临秘境 地点名` 进入；在秘境内使用 `#秘境寻宝` 探索，使用 `#逃离` 带走已获得的收获并离开。若寻宝战败，机器人会结算并说明战败地点与层数。

仙古秘境：发送 `#进入仙古秘境` 进入，再使用 `#秘境探索` 等仙古秘境专属指令。用 `#秘境状态` 查看状态，按游戏提示撤离。

## 交易与社交

- 灵石转账：`#转账 @道友 数量`。
- 拍卖上架：`#上架 物品名 数量 单价`；使用 `#拍卖行` 浏览挂单。
- 赠送可交易物品：`#赠送 @道友 物品名*数量`。装备和唯一物品不可赠送。
- 赠送道侣花篮：`#赠予花篮 @道侣`。
- 源石玩法：使用 `#源石坊` 查看赌石，`#源石坊对决` 开始 NPC 对决，`#镇园石王` 查看本群每周活动。

各玩法可能有境界、冷却、费用或物品要求；使用对应帮助页查看详情。

## 官方 QQ 群

为减少主动消息打扰，群主使用 `#邀请群加入推送` 登记群聊，再用 `#群推送分类 时代 每日 拍卖 活动` 选择推送类别。群主或机器人主人可发送 `#退出群推送` 让本群退出。机器人只有在群允许主动发送消息时才会推送。

道具发放由群主或机器人主人创建发放单。玩家私聊机器人发送 `#领取发放 发放单号` 领取；如果私聊与群内账号身份不一致，再由被 @ 的账号在原群发送 `#确认发放 单号`。请勿为领取公益道具付费。

## 查找指令

- `#修仙帮助`：查看帮助目录。
- `#基础帮助`：查看基础指令。
- `#修仙助手`：按当前角色进度查看建议。
- 在帮助目录中选择职业、宗门、诸天、活动或具体玩法页面。

指令会随版本调整；游戏内帮助和实际指令回复优先于旧截图或第三方攻略。
