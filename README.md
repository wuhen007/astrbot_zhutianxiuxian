# 诸天修仙

面向 AstrBot 的群聊文字修仙插件。包含角色成长、职业与装备、秘境探索、战斗、宗门社交、位面事件和长线剧情。项目以 Python 重构，玩法参考[上游原作](https://gitee.com/mo-wuming/zhutianxiuxian1.0)；各玩法以本仓库当前实现为准，不承诺与原作逐项相同。

## 安装

要求 AstrBot `>=4.0,<5`。在插件管理中安装：

```text
https://github.com/wuhen007/astrbot_zhutianxiuxian
```

也可手动克隆到插件目录：

```bash
git clone https://github.com/wuhen007/astrbot_zhutianxiuxian.git \
  AstrBot/data/plugins/astrbot_zhutianxiuxian
```

安装后重启 AstrBot。插件元数据声明支持 `aiocqhttp`、`qq_official` 和 `qq_official_webhook`；具体消息能力受平台接口限制。

## 开始游玩

在群聊发送 `#踏入仙途` 创建角色，再发送 `#修仙状态` 查看进度。常用入口：

- 日常成长：`#修仙签到`、`#闭关 120分钟`、`#出关`、`#突破`、`#炼体突破`；练气/炼体上限随诸天位面等级解锁。己道首次成功推演至第 20 层会触发原版十方位面损伤并扣减现世承受力，不会封锁位面。
- 造化与时间线：仙帝、祭道及祭道之上可用 `#造化万物 物品名 [数量]` 消耗现世承受力限时造物；到期后再次发送命令领取，领取会增加因果债。仙帝每件消耗 ceil(售价/100)，祭道 ceil(售价/10000)，祭道之上免费；承受力低于 100 万时仙帝/祭道有 40% 始祖扼杀风险：会从人体秘境、仙古、花粉中按当前最高等效权柄路线选一条跌一级；若跌过仙帝权柄线，会失去仙帝资格与帝号、重置己道推演，并使自身之道退回准仙帝待重证。超维造物和岁云造物仍使用各自资源规则。
- 时间线权能：个人因果债达到第三档（600 点）后，后续债务结算会按全服轮转挑选位面清算；每次最多处理 3 个损伤单位，每个入选位面增加 10 点损伤（上限 100），每目标最多扣除 10 万现世承受力。若当前没有可处理位面，未完成单位会保留待结算；位面损伤不会关闭界门。
- 任务与背包：`#获取每日任务`、`#我的任务`、`#提交每日任务`、`#我的纳戒`。
- 秘境列表：`#秘境` 查看地点，`#降临秘境 青冥山` 进入程序化秘境，之后用 `#秘境寻宝` 探索、`#逃离` 结算离开。
- 仙古秘境是另一套玩法：用 `#进入仙古秘境` 进入，发送 `#秘境探索` 等指令继续。

`#修仙帮助` 查看帮助目录，`#基础帮助` 查看常用指令。参数、解锁条件和当前可用玩法以游戏内帮助与机器人回复为准。

## 玩法

- 角色创建、练气与炼体成长、命格、灵根、功法和日常任务。
- 闭关、秘境、Boss、PVP、职业采集、炼丹锻造、装备与物品交易。
- 宗门、师徒、道侣、拍卖、源石坊对决、镇园石王等群体玩法。
- 位面探索与修复：`#修复位面`（无参）由仙帝提升诸天位面承受力；`#映照位面名` 消耗修为/血气重塑单个位面；群主或机器人主人可用 `#恢复位面名` 免费重开界门，`#恢复诸天位面` 可回滚祭礼造成的全部可逆封锁。帝关失守等符合原版来源的毁灭，会随诸天纪年自然修复。修复后玩家可再次进入位面并参与落在该位面的事件。
- 诡异大祭活动期间会启动独立位面毁灭时钟：活动开始 10 秒后进行首轮，之后每 2000 个诸天年最多随机封闭两个未毁、未护持的目标位面。黑暗动乱活动期间，权柄 16 档以上可用 `#救场黑暗动乱`，每场一次保护当前所在的合格位面；低于准仙帝门槛的受影响玩家记入永寂名单，准仙帝以上迁往凡间。玩家档案保留，不删除。
- 仙宠栖息地、工坊、作息、守卫、偷菜与野外驯服。
- 原版流程对齐中的鱼王、宗门神兽赐福、功法传授、天魔炼化和多阶段隐藏支线。

功能开放受境界、职业、道具、群设置和平台能力影响。普通 `#渡劫` 已逐道结算肉身劫并在通过后进行九转元神劫；为适配群聊指令，略去了原版逐道等待；草药逐波消耗和主要复活后续效果已接入；元神九转依原版不触发复活功法，原版逐道等待省略。圣墟和法身圣墟、时间长河、界海均已接入对应战斗结算；法身长河败退仅扣法身气血，不触发真身待援、炼化或过去身惩罚；低于三成气血时下次法身长河行动可按原版消耗起死回生丹恢复。普通天骄讨伐已接入护道人、保命法宝及盘古幡等规则，奖励和共享战斗按本地尺度适配。
原版 `#证道`（人体秘境）与 `#冲关`（仙古）命令职责已恢复。人体秘境可推进至悟道与仙域承载阶段，并衔接路线专属破王成帝劫凭据；普通体质四极阶段按经卷和源石突破，荒古圣体四极有 60 息持久化护道、护道人资源消耗及成功/失败结算。仙古已接入神火后第二、第三道仙气试炼、第 12 境九天十地与第 13 境斩仙铡刀专属劫，以及第 8–19 境高阶冲关的逐波结算；仙古战斗按原版波次/理论攻击和可映射体质、防御、复活效果结算。仙古战斗仍保留端口适配：原版逐波等待省略，部分阵纹/帝兵/功法后续效果未完整覆盖，修为血气沿用本地千分之一尺度。
势力考核、剑云海令牌/秘库、动态赋名装备导入与实例属性保留已按固定原版规则接线。沉迷秘境使用四个本地自定义地点，因无法与原版地点价格一一对应，仍沿用本地灵石费用；新档囚牢之主默认启用也属于安装适配。具体对齐项、数值适配与剩余差异见 [更新日志](CHANGELOG.md) 和本地移植核对记录。

当前工作区改动尚待统一本地实测和质检，版本号会在用户确认进入推送阶段后更新。
### 已核对的玩法细节

- **源术 NPC 对决**：`#源石坊对决` 选择对手；玩家从五块源石中选三块，NPC 也从自己的石池择三，石相组合会影响切源结果，并按平注、加注或豪赌结算。
- **圣墟残页合成**：圣墟副本胜利可获得呼吸法残页；集齐同种五张后，可用 `#合成呼吸法 名称` 合成对应功法。`#圣墟副本` 会显示副本位面、花粉境门槛、基础耗时与资源消耗。

## QQ 群功能

官方 QQ 机器人有主动消息额度限制。群主可使用 `#邀请群加入推送` 登记群聊，并用 `#群推送分类 时代 每日 拍卖 活动` 选择推送类别；群主或机器人主人可使用 `#退出群推送` 停止本群全部推送。主动推送只发往已登记且允许机器人发送消息的群。

群主或机器人主人可创建道具发放单。玩家通过私聊机器人领取；当群聊与私聊账号身份不一致时，需要被 @ 的玩家回到原群确认。发放流程是公益功能，请勿为领取道具付费。

## 配置与数据

- `ACCESS_CONTROL.WHITELIST_GROUPS`：限制可使用插件的群号；留空时不按群号限制。
- `RENDER_ENABLE`：启用图片面板渲染；需要可用的 Playwright/Chromium 环境。不可用时支持的面板回退为文本。
- SQLite 数据库和面板文件位于 `data/plugin_data/astrbot_zhutianxiuxian`。首次启动时会把旧目录 `data/plugin_data/zhutian` 中缺少的数据复制到新目录，不会自动删除旧目录。

升级前建议备份插件数据目录。数据库迁移在启动时执行。
